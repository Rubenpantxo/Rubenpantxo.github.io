# Precios del configurador de alcance

Regla de Rubén (26-11-2026): **precio = media del sector − 20 %**.

Método: para cada servicio se toma el rango que publica cada fuente para un trabajo comparable, se hace la media de los mínimos y la de los máximos, se multiplica por 0,8 y se redondea a 50 € (5 € en la cuota mensual). Precios publicados por agencias y freelance españoles en 2026; casi ninguna fuente aclara el IVA, así que se toman como sin IVA. Son webs de proveedores con interés comercial: sirven de orientación, no de estudio de mercado.

| Servicio | Fuentes | Media del sector | Precio Rubén (−20 %) |
|---|---|---|---|
| Web a medida (≈5 secciones) | 6 | 1.325–4.250 € | 1.050–3.400 € |
| Experiencia 3D (web + módulo 3D) | suma de las dos medias | 3.833–11.650 € | 3.050–9.300 € |
| Automatización (2–5 flujos) | 4 | 1.172–3.350 € | 950–2.700 € |
| Panel de administración | 2 (ver nota) | 2.800–6.750 € | 2.250–5.400 € |
| Tienda online (extra sobre la web) | 9 | 1.692–4.278 € | 1.350–3.400 € |
| Módulo 3D de un producto | 4 | 2.508–7.400 € | 2.000–5.900 € |
| Integración IA / API (asistente) | 5 | 1.440–2.625 € | 1.150–2.100 € |
| Multidioma (un idioma, sin traducción) | 3 (pocos datos) | 153–362 € | 100–300 € |
| SEO avanzado (auditoría y puesta a punto) | 3 | 267–1.533 € | 200–1.250 € |
| Mantenimiento mensual | 5 | 52–118 €/mes | 40–95 €/mes |

Notas:

- **Tienda online**: las fuentes dan el precio de la tienda completa (media 3.017–8.528 €). Como bloque extra se le resta la media de la web base.
- **Experiencia 3D**: solo dos fuentes dan una web 3D completa, y son experiencias inmersivas de varias escenas (desde 8.000 € y desde 18.000 €). El perfil de Rubén es una web de soporte con una escena, así que se calcula como web + módulo 3D.
- **Panel de administración**: las fuentes de «app o herramienta a medida con panel» (Yeeply 6.000–18.000 €, Appyweb 8.000–20.000 €, Niom y Arteco 8.000–30.000 €) son aplicaciones completas, no un panel dentro de una web de pyme. Se usan las dos más comparables: WebsBarcelona (reservas con panel, 600–1.500 €) y Niom (herramienta interna, 5.000–12.000 €). Con las cuatro primeras saldría 3.900–10.300 €.
- **Multidioma**: dos de las tres fuentes son plataformas de plantillas con precios antiguos (30 € por idioma). Dato poco fiable.
- **Urgente (+25 %)** y **descuentos de paquete (5 % y 10 %)** no tienen referencia de mercado publicada: son decisión comercial.
